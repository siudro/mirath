# مِيراث — تطبيق الويب

مساعد ذكي للعناية الآمنة بالجروح، للناس الذين لا يصلون بسرعة إلى رعاية صحية.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة |
| `style.css` | التصميم (RTL، موبايل) |
| `prompt.js` | **نص نظام مِيراث** — منقول حرفيًا من تعليمات الوكيل |
| `app.js` | منطق المحادثة، الصور، والاتصال بـ Gemini |

## التشغيل

**لا يحتاج تثبيت.** افتح `index.html` في المتصفح مباشرة، أو:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## المفتاح

اضغط ⚙ وأدخل مفتاح Google AI Studio من
<https://aistudio.google.com/apikey> — مجاني.

**المفتاح يُحفظ في متصفحك فقط** (`localStorage`) ولا يُرسل لأي جهة غير Google.

> ⚠️ **للنشر على GitHub Pages:** لا ترفع المفتاح. الصفحة المنشورة تعرض زر ⚙ لكل مستخدم يدخل مفتاحه.
> أو قيّده من Google Cloud (HTTP referrers + quota).

## ما يفعله

- **إرشاد أولًا** ثم سؤال واحد فقط — لا استجواب
- **الطب القديم في كل جواب** مع حكمه: ✅ مثبتة / ⚠️ غير مثبتة / ❌ غير موصى بها
- **يدعم الصور** — يصف، ثم يسأل، ثم يرشد (ولا يحكم بالبساطة من صورة)
- **الطارئ** — طبيب فورًا، بلا أي عشب، بلا أسئلة
- **لا تشخيص، ولا دواء، ولا جرعات**
