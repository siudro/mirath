# مِيراث — مساعد العناية الآمنة بالجروح

مساعد ذكي للإسعاف الأولي للجروح، للناس الذين لا يصلون بسرعة إلى رعاية صحية — في
المناطق النائية والمتضررة ومناطق النزاعات، حيث لا يوجد مستشفى قريب.

**الطالبة:** حنين محمد · **المسار:** WAICY 2026 — LLM & AI Agent · **الموعد النهائي:** ٢٣ تشرين الثاني ٢٠٢٦

> المبدأ الذي كتبته الطالبة بنفسها:
> «هدفك مساعدة الإنسان وحمايته، وليس إثبات صحة الطب القديم أو الدفاع عنه.»

---

## ما يفعله مِيراث

يرى صورة الجرح أو يقرأ وصفه، ثم — بالترتيب الصريح:

1. **يفرز الخطورة أولًا.** نزيف شديد أو إصابة انفجار = طلب إسعاف فورًا، بلا أعشاب وبلا سؤال.
2. **يعطي الإرشاد الأولي فورًا** — ٢ إلى ٥ خطوات قابلة للتنفيذ الآن.
3. **ثم** يسأل سؤالًا واحدًا فقط، إن كان الجواب سيغيّر النصيحة.
4. **ثم** يذكر ما يقوله الطب القديم في جرح مثل هذا، **ومعه حكمه الصريح** — ✅ / ⚠️ / ❌ — ومصدره.

كتب لا يُدفع ثمن أخطائها: لا تشخيص، ولا أدوية، ولا جرعات، ولا حكم بالخطورة من صورة وحدها.

## المعمارية

```
               المستخدم (صورة + نص)
                        │
                        ▼
         ┌──────────────────────────────┐
         │   /api/chat  (SSE — حيّ)     │
         └──────────────────────────────┘
                        │
   ①  فرز الخطورة — قاعدة صريحة، لا نموذج
   ②  قراءة الصورة — النموذج يصف ما يراه فقط
   ③  استرجاع من قاعدة الأدلة (data/knowledge-base.js)
   ④  بحث علمي — Europe PMC (بلا مفتاح إضافي)
   ⑤  كاتب — luna-gpt6 (رؤية)
   ⑥  مدقّق مستقل — نموذج ثانٍ يبحث عن الخطأ
   ⑦  بوابة قائمة التحقق (config/checklist.js) — ٩ بوابات آليّة
   ⑧  صورة المادة المقترحة — Wikimedia Commons (مع الترخيص)
                        │
                        ▼
                    الرد النهائي
```

كل خطوة **تُعلن عن نفسها في الواجهة** قبل أن تبدأ، بحركة نباتية هادئة، ثم تظهر
المنتيجة. المستخدم يعرف أن العمل يجري — لا يحدّق في شاشة جامدة وهو يتألم.

## الملفات

| الملف | الوظيفة |
|---|---|
| `prompt.js` | نص نظام مِيراث (نص الطالبة، كلمة بكلمة) + طبقة تشغيل محدودة وموسومة |

| `public/` | الواجهة: HTML، CSS، JS — RTL، موبايل، حركة تحترم `prefers-reduced-motion` |
| `tests/` | ٥ مجموعات اختبار، ١٢٩ اختبارًا |

## التشغيل محليًا

```bash
# ١. الاعتماديات
npm install

# ٢. المفتاح — في .env، وليس في الكود
cp .env.example .env
# افتح .env واملأ OPENAI_API_KEY

# ٣. التشغيل
npm start
# ثم افتح http://localhost:8080
```

**المفتاح لا يُرفع أبدًا.** `.env` مستثنى من Git. الخادم يقرأ `OPENAI_API_KEY` من البيئة
فقط، ولا يعيده في أي رد ولا في `/api/health`.

## النشر على Railway

1. اربط المستودع في Railway. يكتشف `Dockerfile` تلقائيًا.
2. في **Variables** اضبط:
   - `OPENAI_API_KEY` — المفتاح
   - `MIRATH_WRITER_MODEL` = `luna-gpt6`
   - `MIRATH_VERIFIER_MODEL` = `luna-gpt6`
3. Railway يضبط `PORT` تلقائيًا. الخادم يقرأه.
4. الصحة: `/api/health` — دفعة Docker تفحصه كل ٣٠ ثانية.

**لا تضع المفتاح في `Dockerfile` ولا في `railway.json` ولا في أي ملف مُتتبَّع.**

## نصّ صريح للحدود

مِيراث مساعد أولي، وليس طبيبًا. لا يشخّص، ولا يصف دواءً، ولا يعطي جرعة.

المعلومات التراثية تُذكر بوصفها سياقًا تاريخيًا مع حكمها العلمي — لا بديلًا عن
الإسعاف الأولي أو الرعاية الطبية.

في النزيف الشديد أو إصابة الانفجار: **اطلب إسعافًا فورًا.**
